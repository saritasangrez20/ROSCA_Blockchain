\subsection{Interface guard}
\label{sec:abi}
The team rule allowed Member C to change contract internals, not function signatures or events. The ABIs
exactly as Member B received them are kept in \code{test/fixtures/abi\_handoff/}, and a test checks
that every function in them still exists with the same selector, outputs and mutability, and every
event with the same signature and indexed fields. The only removal is \code{getHistory()} (G4), which no
off chain code used. Additions: \code{CircleFactory.implementation()}, \code{Circle.totalPausedTime()},
\code{Circle.PAUSE\_COOLDOWN()}. Member B's end to end tests, which load ABIs from the compiled
artifacts, pass unchanged.

\subsection{Live check of the whole stack}
On a local Hardhat node with sample circles, the indexer and API, the keeper and the web app, we
checked by hand that: the sample circles (all clones) show the right deposits, payments and history;
pause, unpause and a second pause behave as in Figure~\ref{fig:pauseui}; after skipping 34 days one keeper
pass settles the active circle, cancels the expired open circle and finalizes the draw that nobody
revealed, leaving no tokens in that circle; the browser console shows no errors; and the frontend
production build succeeds.

\subsection{How to run}
\begin{lstlisting}[language={}]
npm install && npm run frontend:install   # once
npx hardhat test                          # 124 tests
npm run test:attacks                      # Member C's 38 attack tests
npm run gas:measure && npm run gas:sheet  # gas of a full circle; rebuild the gas sheet
npx hardhat node                          # terminal 1: local chain
npm run seed:local                        # terminal 2: deploy and create sample circles
npm run dev:services                      # indexer + API, keeper, web app (port 5173)
\end{lstlisting}
The system is deployed to the local Hardhat network for the demo; a Sepolia deployment was optional
and was not needed to show any workflow.
