\section{Work Distribution}
\label{sec:contrib}

The code moved as a relay: A built the contracts, B built everything on top of them, and C hardened,
measured and documented the result. While one member held the code, the others did work that needed no
merged code (use case writing, wireframes, threat model draft, report skeleton). Commit history on the
repository is the evidence.
