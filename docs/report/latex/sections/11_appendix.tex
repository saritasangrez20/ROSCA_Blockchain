\subsection{Settlement of a round (excerpt)}
The core of \code{Circle.settleRound} after the optimizations: one read of the paid bitmap, a loop over
unpaid members only, then debt repayment and deposit refill for the recipient.

\begin{lstlisting}[language=Solidity]
uint256 bits = _paidBits[r];
uint256 everyone = (1 << n) - 1;
require(bits == everyone || block.timestamp > roundDeadline(), "Circle: round still open");
address recipient = order[r - 1];
uint256 pot = 0;
if (bits == everyone) {
    pot = n * c;
} else {
    for (uint256 i = 0; i < n; i++) {
        if ((bits >> i) & 1 == 1) { pot += c; continue; }
        address m = order[i];
        _member[m].defaults += 1;
        reputation.recordDefault(m);
        if (m == recipient) { emit MemberDefaulted(r, m, 0, 0); continue; }
        uint256 covered = vault.slash(m, c);       // 100% for members already paid out
        uint256 uncovered = c - covered;
        pot += covered;
        if (uncovered > 0) { shortfall += uncovered; debtOf[m] += uncovered; deficitOf[recipient] += uncovered; }
        emit MemberDefaulted(r, m, covered, uncovered);
    }
}
// 1. repay the recipient's own debt first  2. refill its deposit to 100%  3. credit the rest
\end{lstlisting}

\subsection{Gas measurement scenario}
\begin{itemize}
  \item Deploy all contracts with \code{scripts/deploy.js}; 4 members with 100,000 mUSD each.
  \item Organizer creates a circle: 1,000 mUSD, 4 members, 30 day rounds, 1 day grace, 7 day join window,
        1 day draw phases, no past defaults allowed.
  \item Members join in a fixed order, commit and reveal; anyone finalizes.
  \item Round 1: slots 1 to 4 pay in that order; settle; slot 1 claims.
  \item Rounds 2 to 4: slot 1 does not pay; slots 2 to 4 pay; time moves 32 days; settle; the recipient claims.
  \item Recorded: every named call, the sum over every transaction, deployment gas and bytecode sizes.
\end{itemize}
